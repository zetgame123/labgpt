# LabGPT — Windows Audio Overlay Assistant

Лёгкий полупрозрачный десктоп-оверлей на **Python + PyQt6** для Windows, который слушает системный звук в фоне, по горячей клавише расшифровывает последний вопрос через **Groq Whisper** и стримит краткий структурированный ответ от LLM (с опциональным контекстом из выбранных файлов/лаб).

## Возможности

- **Захват системного звука без виртуальных кабелей** — непрерывный кольцевой буфер через Windows WASAPI Loopback (`PyAudioWPatch`) с выбором конкретного устройства вывода в настройках (динамики, наушники, виртуальные выходы).
- **Быстрый бесплатный стек на Groq API**:
  - `whisper-large-v3-turbo` — быстрое распознавание русской и английской речи;
  - `openai/gpt-oss-120b` (а также `qwen/qwen3.8-27b`, `openai/gpt-oss-20b`) — стриминг ответа и опциональный веб-поиск (`browser_search`).
- **Контекст из файлов / лабораторных работ** — прикрепление отдельных файлов (`.py`, `.ts`, `.js`, `.cpp`, `.cs`, `.java`, `.sql`, `.md`, `.ipynb` и др.) или целой папки. Автоматический контроль бюджета токенов (целиком до 14K символов, либо умный отбор релевантных фрагментов при большом объёме).
- **Исключение из захвата экрана** — использует WinAPI `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)` (окно не попадает на демонстрацию экрана и скриншоты), скрыто из панели задач и `Alt+Tab`, поддерживает режим «клики сквозь окно».
- **Удобный UI** — полупрозрачное тёмное окно поверх всех окон, корректный рендер Markdown и дженериков (`Partial<T>`, `Pick<T, K>`), ручное поле ввода, иконка в трее.

## Требования

- **Windows 10 (2004+)** или **Windows 11**
- **Python 3.10 – 3.12** (64-bit)
- Бесплатный API-ключ [Groq](https://console.groq.com/keys)

## Установка и запуск

### Быстрый способ
1. Склонируй репозиторий и запусти `setup.bat` — он создаст `.venv`, установит зависимости и подготовит `.env`.
2. Запусти `run.bat`.
3. Нажми **⚙** в правом верхнем углу окна, вставь `GROQ_API_KEY` и нажми **OK**.

### Вручную
```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\pip.exe install -r requirements.txt
copy .env.example .env
.\.venv\Scripts\python.exe main.py
```

## Горячие клавиши (по умолчанию, переназначаются в ⚙)

| Комбинация | Действие |
|---|---|
| `Ctrl + Shift + Space` | Ответить на последний вопрос из системного звука |
| `Ctrl + Shift + H` | Скрыть / показать оверлей |
| `Ctrl + Shift + C` | Очистить ответы, историю диалога и буфер звука |
| `Ctrl + Shift + T` | Вкл/выкл режим «клики сквозь окно» |

## Структура проекта

```text
├── main.py             # Точка входа
├── hotkeys.py          # Менеджер глобальных горячих клавиш с переназначением на лету
├── overlay_ui.py       # PyQt6 оверлей, окно настроек и окно выбора файлов контекста
├── audio_capture.py    # Кольцевой буфер системного звука (WASAPI Loopback)
├── ai_client.py        # Клиент Groq API (Whisper STT + LLM streaming)
├── context_store.py    # Загрузка файлов/папок и подбор фрагментов под лимит токенов
├── win_stealth.py      # WinAPI WDA_EXCLUDEFROMCAPTURE и click-through
├── config.py           # Загрузка и сохранение настроек (.env)
├── setup.bat           # Автоматическая настройка окружения
├── run.bat             # Запуск без консольного окна (pythonw)
├── requirements.txt    # Зависимости Python
└── .env.example        # Шаблон конфигурации
```
